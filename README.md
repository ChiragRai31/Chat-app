
# Type08 - Real-Time Chat Application 💬

Type08 is a full-stack real-time chat application built using the **MERN stack**, **Tailwind CSS**, and **Socket.IO**. It supports one-to-one messaging, typing indicators, and real-time message delivery – making conversations seamless and interactive.

## 🚀 Features

- 🔐 User authentication (JWT-based)
- 💬 Real-time one-to-one chat
- 🧠 Typing indicator with live feedback
- 📡 Socket.IO-powered instant message delivery
- 🪄 Beautiful UI with Tailwind CSS
- 🌐 Deployed on Render

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Tailwind CSS
- Axios
- Socket.IO Client

**Backend:**
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication
- Socket.IO Server
